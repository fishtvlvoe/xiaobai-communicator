譯神 Awesome-Eason

把難懂的話翻成聽得懂的話。複製下面這段，貼到你的 AI 設定裡，之後打幾個關鍵字就會自動換一套講法。

按下去就複製好了，接著往下看要貼去哪裡。

貼去哪裡？

  1. 打開 ChatGPT，點左下角你的頭像 → 「設定」→「個人化」
  2. 往下捲到「關於你」區塊，找到「更多關於你的資訊」那一欄
  3. 把剛才複製的內容貼進去，按「儲存」

ChatGPT 這個欄位比較像「補充資訊」，權重沒有 Claude、Gemini 高，效果可能打點折。如果發現它沒完全照規則講話，可以在對話一開始再貼一次完整內容當提醒。（這裡教的是「個人化設定」，跟新聞在講的「自訂 GPT／GPT Store」是兩回事，不受那個消息影響，可以放心用。）

  1. 開一個新對話
  2. 把剛才複製的完整內容，當「第一句話」貼上去送出
  3. 接著才打你真正想問的問題

Gemini 沒有像 ChatGPT、Claude 那種「貼一次、之後都生效」的設定欄位。原本可以用「Gem」做出類似效果，但 Google 預告要在 2026/10/20 關閉這個功能，這裡先不建議用。缺點是每次開新對話都要重貼一次，優點是人人可用、不受任何功能異動影響。

  1. 打開 Claude.ai，建一個新的 Project（專案）
  2. 進到 Project settings，找到「Project instructions」欄位
  3. 把剛才複製的內容貼進去，存檔
  4. 之後在這個 Project 裡開的對話都會自動套用
  1. 這幾套工具不用複製貼上，打開終端機（Terminal）跑一行指令就會自動裝好：
curl -fsSL https://raw.githubusercontent.com/fishtvlvoe/Awesome-Eason/main/install.sh | bash

不知道自己是哪種 AI？打開你平常用的那個網站，找「設定」裡有沒有「自訂指令」「Custom Instructions」這幾個字，就是它。
