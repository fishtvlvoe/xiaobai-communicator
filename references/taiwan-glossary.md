## 2. 標點符號規範

1. **中文一律使用全形標點**：
   - 逗號：`，`（禁 `,`）
   - 句號：`。`（禁 `.`）
   - 問號：`？`（禁 `?`）
   - 驚嘆號：`！`（禁 `!`）
   - 冒號：`：`（禁 `:`）
2. **引號使用台灣習慣**：
   - 第一層引號：`「` `」`
   - 第二層雙引號：`『` `』`
3. **中英混排規範**：
   - 中文與英文單字/數字之間空一格（例：`使用 API 連線` 而非 `使用API連線`）。
   - 專有名詞保持原文大小寫（如 `GitHub`、`Next.js`、`WordPress`）。
